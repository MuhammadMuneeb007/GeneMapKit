\section*{Supplementary Section S1: Scope of the Supplementary Analyses}

This supplementary file documents the data sources, database builds, validation strategy, and benchmark outputs used to evaluate GeneMapKit. GeneMapKit constructs a local SQLite database from pinned public annotation resources and performs human identifier conversion without requiring live API access during routine use. The analyses below distinguish between independent held-out validation, final database diagnostics, external API concordance, and all-to-all path consistency. External API concordance is reported as agreement with external services and should not be interpreted as absolute biological truth.

The raw snapshot used for the analyses was created for \textit{Homo sapiens} (NCBI taxon 9606), Ensembl release 116, with manifest timestamp \texttt{2026-06-14T23:54:25Z}. The final GeneMapKit database used schema version \texttt{2.1.0}.

\section*{Supplementary Section S7: Held-Out Validation Strategy}

Held-out validation used databases built after excluding specific validation sources. MANE held-out validation used a database built without \texttt{mane\_summary}. NCBI held-out validation used a database built without \texttt{ncbi\_gene2ensembl} and \texttt{ncbi\_gene2refseq}. Each benchmark used complete truth sampling (\texttt{--sample 0}) and the \texttt{all-supported} mapping policy.

  --db data/build/genemapkit_mane_heldout_v21.db \

  --require-held-out \
  --sample 0 \

  --out results/mane_heldout_complete

python validate_database.py \

\section*{Supplementary Section S9: Complete All-Gene Publication Benchmark}

The complete publication benchmark evaluated GeneMapKit on all 44,997 approved human gene symbols in \path{data/sample/all_human_genes.csv}. This run combined local identifier conversion, local coordinate lookup from the pinned Ensembl GTF, multi-API external concordance, complete held-out validation summaries, and all-to-all path consistency. The local performance benchmark used one repeat (\texttt{--repeats 1}) for the all-gene run reported here. External API timings were measured from uncached live queries in this run.

\section*{Supplementary Section S12: Mapping Policy Interpretation}

GeneMapKit reports several mapping policies to support different use cases. The \texttt{all-supported} policy returns every direct supported assertion and is recall-oriented. The \texttt{authoritative} policy prioritises configured source authorities for each output namespace. The \texttt{corroborated} policy requires support from at least two independent sources and is precision-oriented. The \texttt{mane-select} policy restricts transcript/protein mappings to MANE Select assertions where applicable. These policies should be selected according to the downstream analysis: broad harmonisation favours \texttt{all-supported}, while canonical transcript/protein analyses may require \texttt{mane-select} or additional filtering.

\section*{Supplementary Section S14: Limitations}

The validation analyses measure recovery of held-out source relationships and concordance with external services. They do not define absolute biological truth. Public identifier databases differ in release timing, accession history, transcript and isoform representation, withdrawn record handling, and cross-reference policy. Disagreement between GeneMapKit and an external service may therefore reflect different database scope rather than an incorrect mapping.

The strongest evidence supports reproducible local conversion for common gene-level identifiers, including symbols, Entrez IDs, HGNC IDs, and Ensembl gene IDs. Transcript-level, protein-level, RefSeq, UniProt, and PDB conversions require more careful interpretation because multiple valid accessions may exist for a single biological entity. The mapping policy should therefore be reported in downstream analyses.

\section*{Supplementary Section S15: Summary}

GeneMapKit integrates 14 public identifier resources into a local SQLite database containing 8,500,203 identifier rows and 29,055,130 direct relationship rows. Independent held-out validation showed strong recovery of expected mappings for MANE transcript-to-protein relationships and gene-level NCBI Entrez--Ensembl relationships. In the complete all-gene publication benchmark, GeneMapKit converted five identifier namespaces for 44,997 symbols in 59.876988 seconds (751.4907 identifiers/s) with offline operation, while live external providers required 100.683602 to 891.083076 seconds. Coordinate concordance between the pinned GTF and live Ensembl lookup was 91.5683\% exact with no conflicts. External concordance against six services demonstrated high precision for core gene-level outputs and highlighted expected lower external-union recall for RefSeq and UniProt identifiers, where external services return broader accession sets. Complete path benchmarking further quantified conversion coverage and round-trip behavior across nine supported identifier namespaces.
